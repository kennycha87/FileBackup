Where should the Active Backup Task Dashboard live?

Consider visibility, accessibility, and workflow

A

New Tab in Main Window

Add an "Active Tasks" tab alongside Jobs, History, Restore, and Settings. Users switch between tabs to see running backups.

Pros

  • Consistent with existing UI pattern
  • Easy to implement
  • Keeps main window clean

Cons

  • Must switch tabs to see progress
  • Less visible when working in other tabs
B

Separate Floating Window

Open a dedicated window that stays on top or floats independently. Can be minimized to system tray.

Pros

  • Always visible alongside main window
  • Can be moved/resized independently
  • Good for multi-monitor setups

Cons

  • More window management overhead
  • Can clutter the desktop
C

Split View in Jobs Tab

Add a collapsible/expandable panel at the bottom or side of the Jobs tab showing active tasks. Always visible when managing jobs.

Pros

  • Visible while managing jobs
  • No tab switching needed
  • Compact when collapsed

Cons

  • Reduces space for job list
  • Only visible in Jobs tab
D

Notification Area / System Tray

Show active task count in system tray icon. Click to expand a popup with task details and controls.

Pros

  • Always accessible from system tray
  • Minimal screen real estate
  • Works well with minimize-to-tray

Cons

  • Limited space for detailed progress
  • Popup may feel less integrated
